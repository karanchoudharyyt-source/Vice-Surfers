# Vice Surfers

GTA x Subway Surfers, built from one prompt.

**Play:** https://karanchoudharyyt-source.github.io/Vice-Surfers/

## The prompt

> Make a mobile-friendly browser game that merges GTA and Subway Surfers: an endless runner through neon Vice City at sunset, cops chasing you, wanted stars climbing to 5, cash to grab, a helicopter, and a WASTED screen. Single HTML file, no assets. Go all out.

- Model: Claude Opus 5.5 (fast mode) in Factory Droid
- One prompt, one response. `index.html` is the model's output byte for byte, with no human edits.
- No images, sprites, or sound files: every building, car, palm tree, and synth note is generated in code.

## Controls

- Phone: swipe left/right to change lanes, up to jump, down to slide.
- Desktop: arrow keys or WASD. P pauses, M mutes.

Survive long enough and the wanted level climbs: roadblocks at 3 stars, a police chopper at 4, maximum heat at 5.
